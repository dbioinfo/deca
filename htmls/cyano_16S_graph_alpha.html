Import data

First we import the subset of data that corresponds to only phylum Cyanobacteriota. Some samples were pruned out due to lacking any ASVs within this phylum, but 761 samples remain.

ps <- readRDS("data/cyano/phyloseq.cyano.tree.rds")
meta <- data.frame(sample_data(ps)) %>% rename("Sample"="SampleID")
otu <- data.frame(otu_table(ps))

Calculate alpha indices

Next we calculate each of the metrics we are interested in, these are Richness, Evenness, Shannon, Simpson and Faith alpha indices.

rich <- vegan::specnumber(otu)
shan <- vegan::diversity(otu, index = 'shannon')
simp <- vegan::diversity(otu, index = 'simpson')
peven <- shan / log(rich)
